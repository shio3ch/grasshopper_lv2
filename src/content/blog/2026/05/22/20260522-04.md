Claude Code CLI 2.1.147がリリースされた。変更数は35件とされ、決定論的なmulti-agent orchestrationに向けたWorkflowツールの追加が大きな見どころになっている。この機能はデフォルトでは無効で、環境変数で有効化する形だ。

既存の`/simplify`は`/code-review`へリネームされ、GitHub PRへのインラインコメント投稿にも対応した。コードレビュー用途での導線が明確になり、AIコーディング支援を実際のレビューフローに接続しやすくなっている。

また、サンドボックスまわりではprototype-pollution対策を含むセキュリティ強化が入った。AI coding agentではツール実行やファイル操作の信頼性が重要になるため、機能追加と同時にエスケープ対策が進むことは実運用上の意味が大きい。
