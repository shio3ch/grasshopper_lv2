Claude Code CLI 2.1.187では、サンドボックス内コマンドから認証情報やsecret環境変数を読ませない` sandbox.credentials `と、remote MCP tool callを5分で打ち切るタイムアウトが追加された。素材では、ハング防止と秘密情報保護の両面で重要な更新として扱われている。

AI coding agentが本番寄りの開発環境へ入り込むほど、便利さ以上に安全性と停止性の設計が重要になる。特にMCP呼び出しの無限待機や、サンドボックス越しの認証情報露出は実運用で深刻な障害要因になりやすい。

派手な新機能ではないが、agentを継続運用する現場にとって必須の土台を固めるアップデートとして高く評価された。
