Claude Code CLI 2.1.187では、サンドボックス実行時の秘密情報保護とremote MCPのハング対策が主要な改善点として共有された。素材によれば、`sandbox.credentials` によりcredentialやsecret environment variablesへのアクセスを防ぎ、remote MCP tool callは5分で中断されるようになった。

この変更は派手な新機能ではないが、AI coding agentを本番運用へ近づける上で重要性が高い。エージェントがシェルやツールを扱う構成では、資格情報の露出防止と、外部ツール呼び出しの停止不能問題が大きなリスクになるためだ。

特にMCPのハング防止は、長時間の自動化ジョブや複数ツール連携での安定性に直結する。AI agentを安全かつ継続的に動かすための基盤整備として、実務寄りの改善が評価された。
