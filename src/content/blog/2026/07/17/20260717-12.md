Visual Studio Code 1.129では、agent workflowを意識した機能強化が複数導入された。素材で注目されたのは、チャットから直接ターミナルコマンドを実行できること、agentが新しいセッションを作成して作業を委譲できること、さらにModern UI previewや独自AIモデル対応が加わった点だ。

これまでIDE内のAI支援は、会話と編集補助が中心だったが、今回の更新では実行と分担まで含めたオーケストレーションに踏み込んでいる。単一の提案ではなく、複雑な作業を複数の文脈に分けて扱う方向へ進んでいることが見える。

AI機能がIDEの周辺ではなく作業フローの中心へ近づくにつれ、エディタはコードを書く場から、エージェントを管理する作業ハブへ変わりつつある。VS Codeの今回の更新は、その変化を象徴するリリースとして受け止められた。
